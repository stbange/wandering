# Decisions

home.lua returns data tables. rules.lua returns on_action(panel,index,slot).
Its result is a whitelisted command; C validates location, supplies, capacity and
duplicate rewards. Invalid/erroring scripts fail without altering state.
An instruction budget stops endless loops.

Recipe costs in the HUD come from the same tables charged by transactions.
Third-party licenses ship beside the executable. Scripts are trusted local mods,
not a security sandbox for arbitrary downloaded code.
