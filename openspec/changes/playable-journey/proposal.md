# Playable journey

Deliver a runnable C/SDL3/OpenGL game with editable external Lua content and a
peaceful complete prepare / pilot / park / explore / return / garden / expand
loop. Establish deterministic commands, persistence and testing before adding
presentation. Develop in increments A–G from the supplied brief.

The requested target set is Windows, Linux, macOS, Emscripten and WebXR.
Compilation is evidence only for the platform actually built. An XR API probe
or desktop screenshot is not headset acceptance. Coverage refers to executable
lines of the authoritative C core and is reported separately from platform,
Lua-loading and rendering integration.
